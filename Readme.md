# Café Natura - Proyecto Pre-Entrega Front-End

Este proyecto es una página web responsiva desarrollada como entrega parcial para el curso de Front-End. Representa la landing page de **Café Natura**, una tienda ficticia de café artesanal y de especialidad.

## Propósito de la Página
El objetivo principal es dar a conocer la marca, mostrar su catálogo de productos destacados, compartir opiniones de clientes satisfechos y brindar un medio directo de contacto para consultas o pedidos.

## Tecnologías Utilizadas
- **HTML5**: Estructura semántica completa (`header`, `nav`, `main`, `section`, `footer`).
- **CSS3**:
  - Google Fonts (`Poppins`).
  - Flexbox para la disposición responsiva de la sección de Productos (cards).
  - CSS Grid para la distribución de la sección de Reseñas.
  - Media Queries para adaptar el formulario de contacto e interfaz a móviles y tablets.
  - Integración de fondas con degradados y background-image.
- **Formspree**: Manejo del envío de datos del formulario de contacto sin backend propio.
- **Multimedia**: Integración de video promocional mediante un `<iframe>` de YouTube e imágenes optimizadas.
